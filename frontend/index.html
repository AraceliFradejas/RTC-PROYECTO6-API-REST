    • Base de datos: MongoDB Atlas + Mongoose

    • GET /api/albums — Todos los álbumes
    • GET /api/songs — Todas las canciones
    • GET /api/songs?title=love — Buscar
    • POST /PUT /DELETE — CRUD completo
